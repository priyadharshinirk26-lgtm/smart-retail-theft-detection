# Smart Retail Theft Detection

## Project Overview

An AI-based retail surveillance system that uses computer vision and deep learning to detect suspicious activities and potential theft in real time.

## Features

- Real-time theft detection
- Computer vision-based monitoring
- YOLOv8 object detection
- Audio alert for suspicious activity
- Video-based detection and analysis

## Technologies Used

- Python
- OpenCV
- YOLOv8
- Deep Learning
- Computer Vision

## Project Files

- `main.py` - Main application
- `detector.py` - Detection logic
- `audio_alert.py` - Audio alert system
- `run.py` - Runs the project
- `requirements.txt` - Required Python packages
- `yolov8n.pt` - YOLOv8 model
- `theft_video.mp4` - Input video
- `theft_video_detected.mp4` - Detection output
